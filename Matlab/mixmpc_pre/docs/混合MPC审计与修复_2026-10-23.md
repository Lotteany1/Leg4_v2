# Leg4 混合 MPC 建模与部署审计

日期：2026-10-23。范围：当前 mixmpc_pre 的 mpc、solver、staging、相关 tool 函数；Leg3_v2 仅只读对照，没有修改旧工程或烧录硬件。修改前的模型、求解器及生成表保存在 `build/audit_before_20261023/`。

本次按用户确认统一轮半径 0.0525 m、单腿质量 1.855 kg、半轮距 0.212755 m。最终架构按用户要求沿用 Leg3 的外层函数补偿方式：模型和求解器负责 MPC，腿部重力、气弹簧、机体向心补偿在输出代码中分别调用。

## 1. 两条原链如何合并

只读对照了以下来源：

- `Leg3_v2/Matlab/TinyMPC/s01_build_tinympc_cache.m` 与 `tinympc_admm_ref.m`：10 态、4 力矩输入的轮腿平衡方程 (19)–(23)，查表调度、ZOH 和预计算 DARE。
- `Leg3_v2/Matlab/TinyMpc_Leg_Len/s03_leglen_tinympc.m`：4 态、2 腿力输入的横滚/高度模型，气弹簧外置、总力箱和力变化率限制。
- `Leg3_v2/Wheel_Leg/Code/Control/balance.c`：轮矩取反，髋矩加 MgF，腿力减气弹簧；VMC 前完成出力装配。
- `Leg3_v2/Wheel_Leg/Code/Estimator/air.c` 与 `Task/leglen_task.c`：实际力估计、气弹簧回加和部署输入口径。

当前状态为：

```text
x = [s, ds, yaw, dyaw, psiL, dpsiL, psiR, dpsiR,
     pitch, dpitch, roll, droll, H-H_REF, dH]
u_mpc = [Twl, Twr, TBl, TBr, FmpcL, FmpcR]
```

psi 是世界腿角，已经包含机身俯仰，不再重复加 pitch。H 状态是相对 H_REF 的偏差，而调度包 H 和实测腿长均为绝对长度。前四个输入单位 N·m，后两个为 N。

它是一套 14/6 连续 LPV MPC。模型是在旧平衡块与横滚/高度块基础上加入部分几何投影，不是已经完成全部七自由度变长动力学推导的非线性整机模型。`kin_ldot` 和 `roll_closure` 的旧开关主要用于推导检查，不能据其名字认定运行核已保留所有变长惯性、科氏和几何闭合项。

## 2. 物理建模问题与修复

### 2.1 参数分叉

原模型的 R_w=0.060、m_l=1.408 与补偿侧 1.855、横滚半距 0.20 相互分叉。现由 `tool/leg4_hardware.m` 提供共享参数，mpc 配置与 Coder 函数读取同一来源；s03 将参数导出到 C 头文件，求解器侧补偿读取该头文件。

统一后的派生值：全轮距 0.42551 m；机身及两腿质量 24.244 kg；含两轮的质量 25.544 kg。M_V=25.544 继续作为旧链的锁定等效竖直惯量参数，不能把“等效惯量恰等于整机质量”解释为已经完成辨识。

查表中的质量分布和转动惯量没有凭空重标。m_l 变更已经重新计算全部矩阵，但表中 I_leg 的参考轴、腿部各质量点位置仍需要 CAD/台架确认。消元方程 M5 非对称本身不能证明物理质量矩阵错误：其方程经过消元、缩放，未必就是广义坐标下对称的拉格朗日质量矩阵。

### 2.2 重复计入水平腿力

旧融合代码在已经消去内力的平衡模型上，继续直接添加：

```text
sdd     += (FL*sin(psiL)+FR*sin(psiR))/Mtot
pitchdd -= lc*(FL*sin(psiL)+FR*sin(psiR))/Ib
```

在直立工作点，变长项对水平运动的影响在本次一阶检查中消失；因此可以直接用旧方程 (21) 检查水平动量。记 awL/awR 为表中的轮到腿质心距离，则必须满足：

```text
-(mb+2*ml+2*mw+2*Iw/Rw^2)*sdd
-(ml*awL+mb*lL/2)*psiLdd
-(ml*awR+mb*lR/2)*psiRdd
+(Twl+Twr)/Rw = 0
```

修复前的一阶矩阵残差约 127.583 N/rad；关闭直接 `F_pitch` 行增项后约 1.63e-13。部署配置的 `sw_fused.F_pitch=0`，试验开关保留。没有用“闭环谱半径小于 1”替代物理一致性证明。

竖直/横滚投影以及轮矩的竖直投影仍保留。这些是当前降阶模型的近似，尚不能用一次守恒检查证明整个七自由度模型在任意倾角/高速运动下都成立。

### 2.3 仿射项被人为锚定

原 `leg4_fused_ab` 先求展开点雅可比，又将 f 改为 `-A*x_eq-B*u_eq`，强制一个其他工作点的平衡解在所有 psi 下成为定点。这种检查可以自动通过，却改变了实际动力学；独立测试在展开点测得约 0.199767 的加速度误差。

现严格使用 `f=dyn(x0,u0)-A*x0-B*u0`。需要检验平衡点时，先求真实平衡，再在那个平衡状态和输入处展开，不再重写物理仿射常数。展开点动力学检查现为数值零。

### 2.4 高度与开关不一致

`leg4_fused_op` 原先将绝对 sched.H 再加 H_REF，多加 0.27 m，已修复。`F_H_proj` 关闭时，原代码只撤销高度行的 cos 投影，横滚行仍保留；现同时控制两行。

### 2.5 模型内外补偿边界

当前采用用户确定的外层结构：

```text
MPC -> u_mpc
Tp      = TB + MgF
Ftotal  = clip_and_slew(Fmpc + Fc)
Fmotor  = Ftotal - Fs
VMC(Fmotor,Tp) -> 电机
```

模型仍需要重力动力学和承重静态输入 u_ss；这和额外调用髋部 MgF 补偿是不同的量。气弹簧刚度固定为零，Fs 不烘进 A/B，也不再平移 MPC 力箱；向心 Fc 不进入 A/B、fed 或求解器 ffwd。C/MATLAB 的 comp.ffwd 兼容字段恒为零。

原仿真把 MgF 再加给已经按补偿口径工作的 B 族 plant，相当于二次作用；现 plant 使用模型坐标输入，真实电机出力单独计算 Tp=TB+MgF。

### 2.6 向心补偿的二倍因子

对称分配 ±Fc 时，力偶为 `2*R_TRK*Fc = TRACK*Fc`，因此：

```text
Fc = M_SUP*v*omega*(Lmean+H_OFF)/TRACK
```

旧 tool 函数已经把 TRACK 定义为全轮距，却又除以 2*TRACK，少补一半。`Leg_RollComp`、`Leg_CoriolisComp` 和独立 C 补偿模块现统一使用全轮距 0.42551。已从 MATLAB 源重新生成 tool/cmsis，未手改生成文件。独立力偶检查、输出装配和补偿后速率限制均已加入回归。

## 3. 优化问题与数值实现

### 3.1 继承的参考代价错误

原 q 项使用 `-(Q+rho*I)*xref-rho*(v-g)`，终端又同时使用完整 Pinf 参考项与终端共识罚项。rho 是共识罚参数，重复写入参考线性项会使非零参考产生偏置。

独立标量凝聚 QP 的首输入误差为 0.0880222；即便处于应当零修正的非零平衡点，原实现仍输出同样的偏置。

当前物理优化目标为：

```text
0.5*sum[(xk-rk)'Q(xk-rk) + (uk-ruk)'R(uk-ruk)]
+ 0.5*(xN-rN)'(Pinf-rho*I)*(xN-rN)
```

对应 ADMM 阶段 Hessian 为 Q+rho*I、R+rho*I；物理线性参考项只使用 Q、R；终端物理线性项使用 Pinf-rho*I。离网点检查同时验证物理终端权正定。

修复后标量 QP 的误差约 4.17e-11，非零平衡点的额外修正约 3.01e-11。旧 s05a “逐行复制 Leg3 算法”不能证明代价正确，现更换为独立检查；旧源码完整留在修改前备份。

### 3.2 七表分别拟合后的 Riccati 不一致

Ad、Bd、K、P、QuuInv、AmBKt 分别做多项式拟合，不保证拟合结果仍满足同一个 DARE。初始版本在标称点的 K 恒等式相对误差约 1.53e-3。

当前保留离线 LPV 表以获得快速调度模型和终端 P。每次模型真正变化时，额外做 7 步有限时域 Riccati 递推，缓存每步 K、QuuInv、转置闭环阵及下一步 P。每轮 ADMM 使用这些一致因子，仿射项也逐步构造。C 实现在新增 `solver/leg4_admm.c`，内部采用双精度工作区，无动态分配。

代价是静态 RAM 和最坏计算量增加；旧内存和时间报告作废，不能沿用旧“轻量预算”直接上机。

### 3.3 链式裁剪不是欧氏投影

ADMM 的 z 子问题要求对整个输入序列投影。原来从第一节点往后依次钳位，只保证可行，不是最近点。例如 w=[10,-10]、首节种子 0、速率 1：前向钳位得到 [1,0]，正确投影为 [0.5,-0.5]。

现采用有界活动集投影，同时处理箱、首节变化率和相邻节点变化率。100 个压力例与 quadprog 最大误差约 9.45e-11；6 个完整 14/6 受约束 QP 与独立凝聚解最大误差约 7.56e-7。

### 3.4 腿长权重丢失了原链比例

实际 Leg3 腿长脚本已使用 Q=[40,25,300,10]、R=[1e-4,1e-4]。融合版却采用 Q=[50,27,100,7]、力 R=1，使高度/横滚相对腿力代价显著减弱。

现在将旧腿长目标整体乘 1e4，取 Qleg=[400000,250000,3000000,100000]、Rforce=[1,1]，保留原 Q/R 比例。rho=10 只影响 ADMM 收敛及所选终端近似，不应再被解释为“收敛后物理权重加 rho”。

Ts=2 ms、NH=8 实际是 8 个状态节点和 7 个控制区间，预测时域为 14 ms；原腿长链对应 70 ms。恢复 Q/R 比例并不等于恢复相同预测时域。先前“16/80 ms”的说明存在节点计数偏差，已在当前说明修正。

### 3.5 LPV 求值与验证

使用归一化腿长坐标 `(L-.25)/.09`，psi 四次多项式，50 系数/元素。C 以双精度累加 float 系数，MATLAB 对应相同系数和输出精度；psi 限定在真实拟合域 [-0.30,0.30]，不再扩大到未验证的 ±0.35。

200 个随机离网点的 Frobenius 相对误差上界约为：Ad 6.66e-4、Bd 1.36e-3、fd 6.59e-7、K 6.61e-5、P 6.10e-4；拟合闭环最大谱半径约 0.999716999。这里的稳定性仅针对检查点，不能外推为整个连续域/任意切换的共同稳定性证明。

## 4. 运行时与部署问题

- 普通不收敛原先调用 Invalidate，连 running 一并清零，之后不会再求解。现普通失败只丢弃序列，显式停用才清 running；有效输入自动恢复。
- 原序列存 bare 输入，却在消费时叠加最新 u_ff。参考/偏置变化后，旧序列会被错误平移。现序列绑定求解快照的偏置，C 发布物理序列；MATLAB 参考等效处理。
- 增加取消代次，在途旧求解不会在 Invalidate/Run 后重新提交。
- 序列年龄按观测采样时刻计算；超龄观测不再反复求解，过期序列不再使用。
- 相同节点重复消费原先没有计数；现检测包含相等情形。
- 发布模型、仿射项和回退增益以同一控制快照读取，明确单求解任务、低优先级生产者、高优先级消费者与可嵌套临界区约定。
- 新增 `Leg4_Comp_Apply`，在外层叠加补偿后再做总力箱和速率限制；新增 `Async_Applied` 回传实际施加量。VMC 后若再饱和，须使用逆 VMC/测量值重新构造反馈。
- 原测试比较函数对 NaN 的差可能不计入最大误差；现显式拒绝非有限输出。收敛标记不一致也使测试失败，不能以“接近容差边缘”豁免超差。
- s07 原先绑定历史硬编码哈希，已有单点 C 文件不匹配。现由各生成器分别写生成物及其模型来源的 SHA-256 清单；改 cfg/模型后未重建会直接失败。
- s02 的可选三字段预览原来能覆盖部署七表。现在仅写 staging/preview。当前部署单点使用 s03、LPV 使用 s04d。
- 非对称工况原先直接改 lL/lR，却保持 alpha=0，控制器反算仍是两腿 0.27 m。现初始 H/alpha 与腿长一致，按真实参考验证，原 G18–G27 门限无需放宽。

## 5. 已执行的验证

`mpc/leg4_build_and_verify.m` 是当前重建及 MATLAB 验收入口，日志为 `build/audit_full_validation.log`。范围包括：单点 G1–G8、表和源文件清单、独立标量 QP、动量不变量、投影压力、真实 14/6 凝聚 QP、200 离网点、7 场景运行时 G18–G27、同步链、3 个 RK4 非线性投影闭环。

核心场景全部通过原门限。持续力扰动下 MPC 最大高度偏差约 7.8 mm；同场景固定 LQR 约 41.2 mm。首轮修复时尚未恢复腿长权重的 MPC 对应约 241.9 mm，仅用它说明权重比例影响，不能将它当作最终模型表现。

非线性投影核检查：站立终端高度误差约 -3.19e-7 m；抬高 5 cm 后约 -9.23e-6 m；横滚速度冲击峰值约 7.49e-3 rad。所有腿长留在 0.16–0.34 m 内。这个 plant 仍由当前降阶物理核构成，不是独立 CAD 多体/实机验证。

C 验收包含 8 固定向量、1000 连续热启动向量、补偿装配、补偿后速率和施加量反馈、NaN、异步节点、失败恢复、取消在途求解、过期观测。最终数值及 ASan 结果见 `build/audit_host_final.log`、`build/audit_asan_final.log`。

最终普通构建与 ASan 构建均 PASS：最大输出差 1.526e-5，小于 2e-4 门限；收敛标记不一致 0 例。最终静态检查通过三份各含 22 项的生成物/模型来源清单，记录在 `build/audit_manifest_final.log`。

Cortex-M7 AC5 交叉编译与链接结果见 `build/audit_arm/link.txt`、`leg4_audit.htm`。增加有限时域缓存和双精度后，静态 RAM 约 52 KB，已知最大调用栈约 5 KB，Flash 约 175 KB；以最终链接文件为准。工具链验证没有运行在 MCU 上，4 ms 最坏求解截止时间尚未实测。

最终最小链接验证工程：RW+ZI=52936 B（51.70 KiB），ROM=179556 B（175.35 KiB）；已知最大调用链栈 5136 B。调用图同时标注主机 port 的不可追踪函数指针，这不是实机栈上界证明；正式 RTOS port 和中断上下文仍需实测。源文件变更索引为 `build/audit_changes.txt`，对应修改前/后差异为 `build/audit_changes.diff`。

## 6. 仍然存在的模型边界

1. 等效竖直惯量、横滚惯量参考轴、阻尼和两张腿参数表仍需实测/CAD 校验。旧气弹簧和重力补偿力臂表不会因三个标量参数统一而自动变成新车实测表。
2. 支持力输入、气弹簧等效广义力、地面法向力需在固件端继续按真实 VMC/air 估计定义确认。旧模型将整机重量用于总力基准，而 air 估计又显式加轮重；完整质量分布模型可能需要区分地面支持与机构轴向力，不能在没有明确力定义时随意改一个质量常数。
3. 当前只按平均 psi 做 LPV 调度；左右腿摆角明显不同时，模型雅可比不能由一维平均角完全表示。高动态变长的 ldot/lddot 惯性项、接触切换、离地模式和完整速度二次项没有覆盖。
4. A_MAX=0.6 rad 是优化状态界，不是几何可达域。腿长行程和横滚/高度是耦合的；单独状态箱不能保证整个预测轨迹满足腿长、摩擦锥和接触限制。7 号应力工况仅作记录。
5. MPC 的髋矩箱和腿力箱不能保证 VMC 后两个电机各自都不超过关节力矩上限。最终硬件限幅、逆映射实际输入反馈及台架验证不可由本次 C 数值对拍替代。
6. 外层向心补偿必须与真实转弯惯性力矩配套。将 Fc 加到一个没有转弯扰动的直立仿真 plant，会主动产生横滚，不能据此调错符号。独立力偶检查验证了现有坐标约定下的力矩平衡。
7. 固定参考 xref 与真实行走轨迹的生成、姿态/速度估计延迟、任务抢占时延、单精度传感器噪声和共同 LPV 稳定性，仍属于实机集成验证范围。

因此，本次交付是可复现验证的修正模型与部署参考代码，不能把现有 PASS 扩大解释为已完成任意工况整机物理建模或实机验收。
