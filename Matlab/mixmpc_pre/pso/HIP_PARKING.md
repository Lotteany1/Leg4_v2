# 旧版驻车与髋力矩核对

基线是已归档的 response_r1_p07。位移 Q 为 310，速度 Q 为 115.5，左右轮 R 为 4.4，左右髋 R 为 1.8。参数与 C 包均取自全参数搜索归档，复算和诊断固件的构建使用隔离目录。

驻车实际注入 `pos.weight × pos.error`。归档固件的完全接入倍率为 0.5，恢复斜坡为 200 ms。行驶模式置零 MPC 位置通道，沿程速度正常反馈。本次仿真对驻车使用已经接入的 0.5。上轮全参数报告的驻车模型采用 1.0，因此旧报告给出的回位时间需要按本次模型条件理解。本次依然是 2.4 s 简化闭环，未模拟驻车重新捕获和电机/轮地的全部动态。

## 同帧诊断

录阻尼辨识数据使用 [54 通道新版](HIP_VOFA_ID.md)。下方保留 33 通道初版的口径。

[旧参数诊断 HEX](build/hip_vofa_old/packages/hip_vofa/arm/Wheel_Leg_Code.hex) 已通过 AC5 编译链接。将 107 源工程的 AC5 输入清单与归档旧版比较，唯一变化是遥测文件 vofa_task.c。通道布局见 [诊断帧模板](hip_vofa.c.txt)。采样周期 10 ms，UART8 JustFloat。

- CH03–09 记录控制模式、里程、相对驻车点误差、位置反馈倍率、捕获计数、实测速度和参考速度。用 CH05–09 判断振荡是否伴随锁点变化、位置回拉或反馈速度变号。
- CH13–16 分别是净髋矩请求和补偿。CH17/18 是合成 Tp 请求，CH19/20 是 CAN 接纳扭矩码反算的合成 Tp，CH21/22 是电机反馈逆解。CH27–30 提供接纳、配对和关节限幅证据。从 CH01/02 及 CH29 对齐请求与接纳，反馈用 CH00。
- CH23/24 和 CH25/26 分别记录轮矩模型请求和接纳。前后向分析用各对左右的同向量。

复算命令为 `python Matlab/mixmpc_pre/pso/check_hip_parking.py`，使用归档版本及其停车权重。逐工况 JSON 在 [复算数据](build/hip_parking_old/firmware_weight/)。
