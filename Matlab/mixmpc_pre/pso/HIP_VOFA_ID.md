# 旧参数 VOFA 髋阻尼录波

使用归档参数 response_r1_p07。此镜像在隔离目录构建，AC5 源文件哈希与旧版相比只有 vofa_task.c 不同。

[诊断 HEX](build/hip_vofa_old_id/packages/hip_vofa/arm/Wheel_Leg_Code.hex) · [构建日志](build/hip_vofa_old_id/logs/hip_vofa_arm.log) · [镜像校验](build/hip_vofa_old_id/verification.json)。

## 录制和导出

UART8，JustFloat，230400 baud，8N1。采样间隔 10 ms，导出 54 列 I0–I53，CH53 每帧为 5402。保留原始 CSV 和时标。导出精度可设置时，角度、角速度和力矩保留至少四位小数。一次试次覆盖静置、平顺起步、松杆到驻车，再连续保留驻车往返和最终静置。分别留正向和反向试次，完整记录腿高和地面条件，以便按整份录波做留出验证。

## 通道

| 通道 | 定义 |
|---|---|
| 00 / 01 / 02 | ms，VOFA 快照 / MPC 计划关联输入 / CAN 执行记录的源状态时标 |
| 03 | 模式，0 驻车，7 地面行驶与制动 |
| 04 / 05 / 06 / 07 | 两髋里程 m / 相对停车点误差 m / 驻车权重 / 累计捕获 |
| 08 / 09 | m/s，反馈 / 目标速度 |
| 10 / 11 / 12 | rad，MPC 记录的俯仰、左腿和右腿矢状角 |
| 13 / 14 | N·m，左、右净髋矩 MPC 请求 |
| 15 / 16 | N·m，左、右髋补偿 |
| 17 / 18 | N·m，左、右合成 Tp 请求 |
| 19 / 20 | N·m，左、右 CAN 接纳码反算合成 Tp |
| 21 / 22 | N·m，左、右髋电机反馈逆解 |
| 23 / 24 | N·m，左、右轮 MPC 请求，模型符号 |
| 25 / 26 | N·m，左、右轮 CAN 接纳码，模型符号 |
| 27 / 28 / 29 | 本拍接纳位 / 保持码有效位 / 计划与接纳配对 |
| 30 / 31 / 32 | 累计关节限幅 / 终端反馈 / CAN 未接纳 |
| **33 / 34** | **rad/s，左、右腿相对机体矢状角速度 dψ−dθ** |
| 35 / 36 | 俯仰欧拉角速度 rad/s / 控制用估计帧时标 ms |
| 37–40 | ms，左前、左后、右前、右后四个髋电机各自反馈帧时标 |
| 41 / 42 | N·m，左、右轮反馈，已换成与 23–26 一致的模型符号 |
| 43 / 44 | ms，左、右轮反馈帧时标 |
| 45 / 46 | m，左、右腿长 |
| 47 / 48 / 49 | 横滚角 rad / 偏航欧拉角速度 rad/s / 高度估计 m |
| 50 / 51 | N，左、右轴力反馈，含执行记录的弹簧力估计 |
| 52 / 53 | 机体系原始滚转陀螺量 rad/s / 布局标识 5402 |

计划与接纳按 CH01、CH02 和 CH29 对齐。髋反馈逆解结合估计帧与四个关节反馈时标判断数据年龄。轮矩反馈使用 CH43/44。用 CH00 的相邻差核对导出间隔和缺帧。CH33/34 的速度方向是腿相对机体，写入动力学时需按髋力矩模型的共轭方向处理。

复建命令为 `python Matlab/mixmpc_pre/pso/build_hip_vofa.py`。
