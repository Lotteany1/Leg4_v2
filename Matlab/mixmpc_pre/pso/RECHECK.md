# TinyMPC14 权重交叉复核

**本轮选定 Rforce_low。** 在复核的参数和工况范围内，按三个工况集各自相对基线的评分取等权平均。每个工况的姿态、横滚和回退继续受原 PSO 门限约束。通过原有构建门限、独立闭环 C 回归和扩展 C 网格后才允许写入实际配置。

## 复核覆盖

- 原 PSO 搜索 88 个位置。复核运行 22 组，包括基线、4 个已搜候选和 17 个单维或联合扰动。原第一名附近检查 0.7/1.4 倍、边界外横滚速度和两腿共用 R 等方向。
- 对四个有竞争力的候选重跑原留出集，并在新 8 组工况中使用随状态更新的非线性动力学与 RK4。工况覆盖升降、转弯、正负冲击、高惯量和长执行滞后。长滞后是超出原搜索范围的压力工况。该非线性核与仓库 S10 共享物理方程。
- 独立固件 C 网格使用生产控制入口、输出分配、CAN 码反算及电机反馈。组合为 3 个横滚惯量、3 组执行延迟与时间常数、3 个求解节奏、2 种扰动方向。诊断网格逐项记录原高度/横滚门限，正常六工况 C 回归仍以原断言验证。
