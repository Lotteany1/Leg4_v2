# 实机 A/B VOFA 通道与对齐

A、B 镜像路径和哈希见 [报告](REPORT.md)。同一负载、电池状态、地面和模式做重复对照，每次保留完整原始 CSV。按静止定高、直行、升降、横滚扰动、转弯升降保留各工况的动作触发或扰动时标。平地双轮承重时先记录静态保持再启动动作，保持录波到恢复。转弯和直行比较另录速度与偏航参考、实际值的同步信号，当前 54 通道帧未包含这些信号。记录板上镜像哈希、采样配置和本次测试的装车质量。

当前串口 UART8，JustFloat，230400 baud，8N1，采样约 10 ms。实际时标由 CH00 判断。剔除无效首帧、重复及跨启动帧。CH20 位 23 为 1 采用以下新格式。50 路历史录波缺 CH50–53，40 路录波缺 CH40–53。旧格式的后台字段语义见 `Wheel_Leg_Code/Code/Config/README.md`。

| 通道 | 含义与单位 |
|---|---|
| CH00，02，03 | 遥测快照、求解输入、最近序列发布时标，ms |
| CH01，04 | 后台尝试与 LPV 更新累计次数 |
| CH05，06，07，09 | 横滚 rad，原始与控制滚速 rad/s，横滚参考 rad |
| CH08，10，12，14，18 | 开始前过龄、坏输入或调度失败、未收敛、返回过龄、代次切换拒绝计数 |
| CH11，25–29 | 原始高度 m，滚轮原值，行为层高度目标，MPC 高度参考，MPC 滤波高度 m，MPC 升降速率 m/s |
| CH13，32 | 分配前总支持力请求差与和，N |
| CH15，34 | CAN 接纳码反算总支持力差与和，N |
| CH16，35 | 电机反馈力矩反算主动轴力差与和，N |
| CH17，36 | 被动气弹簧估计差与和，N |
| CH19，24，37 | 后台墙钟耗时 µs、ADMM 迭代次数、实际输入返回年龄 ms |
| CH20，21 | 标志位与执行模式。位 20 接地、21 配对、23 新后台语义 |
| CH22，23，38，39 | 终端回退、预测过龄、成功提交、关节请求越界累计计数 |
| CH30/31，46/47 | 左右实测腿长 m 与矢状角 rad |
| CH33 | 分配后的两腿合力，N |
| CH40/41/42，43/44/45 | 预测、回退各自最近的 CAN 接纳时标 ms 与总力和/差 N，-1 为无有效时标 |
| CH48，49 | 同拍 Y 比力 g 与俯仰角 rad |
| CH50–53 | 两腿有效位；左右已建立力估计减接纳力 N；降高分配削减合力 N |

- 分配前请求用 CH32/13。实际入队的关节命令反算力用 CH34/15。同拍配对按 CH20 位 20/21。近期预测与回退拍的力分别用 CH40/43 对齐、去重，再用 CH02 把参考映射到相同控制时间轴。
- 两腿合力 S、左减右差力 D 均包含被动弹簧时，左/右为 (S±D)/2。反馈估计的 S 用 CH35+36，D 用 CH16+17。CH50 按左右腿作用，CH51/52 随对应有效位读。电机力矩反算和估计弹簧不能替代轮地测力。
- 高度看 CH27→28，同时看 CH26→11。横滚看 CH09→05，滚速看 CH06→07。以完整动作段算 10% 响应延迟、最终参考超调、误差带稳定时间、扰动后恢复时间及姿态峰值。覆盖同阶段时比较单腿触及 20 N 或 150 N、合力均值、差力 RMS。
- 用 CH00 时差计算 CH22 回退比例，配合 CH01、CH14、CH23、CH38 增量及 CH37 年龄。CH19 和 CH24 仅代表最近一次后台调用。10 ms 导出不足以逐拍验证 3 N/ms 限速，需要接纳记录的控制拍级采样。
