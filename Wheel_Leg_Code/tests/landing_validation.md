# 触地直入 MOVING 验证

## 控制链与初值

正常流程为 `AIR → MOVING → STANDING`。确认触地当拍进入 MOVING 并使用普通行驶分配。恢复窗口内暂停机身纵向速度参考跟踪和对应的 Kinf、LQR 速度分项，姿态、腿长和高度继续闭环。腿长 MPC 快环从触地播种力起限制左右共同支撑力的单拍变化，差力按原请求保留。恢复窗口结束后恢复速度跟踪并开始累计驻车判稳时间。连续判稳并满足原驻车条件后捕获当前位置，位置权重沿原 200 ms 斜坡恢复至 0.5。

伸腿方向为正。两侧 `d_len` 都来自 `Leg_Spd(...)[0]`，右侧镜像只反转摆角和摆角速度。`Fs = -SpringF` 是被动弹簧轴向力。`S0` 是地面合成中的名义总支持力。腿长 MPC 的发布力已含横滚前馈，快环从裸力加回本拍前馈后恰好恢复发布总力。纯 PID 路径则使用原有腿长、横滚和固定支撑前馈。转弯扰动力进入预测，髋补偿走原力矩链。

落地恢复时两腿共用气弹簧补偿比例 `p`。电机轴向候选力为 `S0 - p * Fs`，普通分配器收到的候选总力为 `S0 + (1 - p) * Fs`。同一比例下，左右被动弹簧力差仍会进入候选差力，大小为 `(1 - p) * (FsL - FsR)`。

| 配置 | 初值及依据 |
|---|---|
| `FSM_LAND_RECOVER_MS` | 30 ms。确认触地就开始，作为补偿、高度合力交接和速度反馈冻结的窗口。设为 0 时立即恢复 |
| `FSM_LAND_SPRING_START_PCT` | 100%。触地首拍保留的补偿百分比。取 100% 时气弹簧补偿全程已满，高度和速度仍按配置的恢复窗口运行 |
| `FSM_LAND_LEN_TGT` | 0.18 m。确认触地时一次写入双腿目标长度和 MPC 目标高度 |
| `FSM_LAND_STABLE_SPEED`、`FSM_LAND_STABLE_ANGLE`、`FSM_LAND_STABLE_OMEGA` | 每腿伸缩速度 0.05 m/s，俯仰与横滚 0.15 rad，二者角速度 0.30 rad/s |
| `FSM_LAND_STABLE_MS` | 气弹簧补偿恢复后，双腿分别超过原 70 N 接触阈值且速度、姿态连续在窗口内 50 ms，才允许驻车。当前 17.5 kg 整车静态均载约 86 N/腿 |
| `AIR_LAND_RELIFT_MS` | 从确认触地到首次判稳之间，双腿都低于原 30 N 离地阈值 12 ms 才重新确认离地。落地沿仍沿用原平均力 70 N、5 ms 确认 |

阈值和持续时间属于工程试验初值。编码器速度噪声、接触估计的实机分布、气弹簧实际预载和机械余量需要在本机记录。

### 力连续性和执行判读

- 触地首拍以当前电机力反馈加实际 `Fs` 播种腿长 MPC。执行历史由关节和轮电机的接纳码重建，MPC 使用同一接地代次可信区间的末值更新力锚。
- 20–200 N 总力箱和 100 N/10 ms 速率约束继续在腿长 MPC 内作用。从触地首拍起，补偿后的执行候选交给 `BALANCE_USE_DISTRIBUTOR` 选中的普通分配策略，当前为 CLIP。关节力矩保护和 CAN 接纳逻辑照常运行。启用 PROJECT 时，150 N 是关节请求超界后用于投影的软支撑边界。
- AIR→MOVING 切代次并废弃在途 AIR 解。野值或超龄平衡序列沿同模型 Kinf 回退。腿长超龄保持上次发布值并计数。触地后高度参考从实测高度起步，首解按实测高度速度及配置的横滚角速度输入播种。补偿恢复和后续驻车共享接地执行代次。
- 高度合力斜坡对两腿等量加减。以原腿长 MPC 的 100 N 单步额度作为每腿共同分量在恢复时长内的变化额度，当前 1 ms 通常允许两腿合计变化 6.67 N。求解时的单腿幅值、速率箱和可行差力优先。窗口结束后继续追平最近发布的高度合力，后台首解迟到时也沿用该斜坡。
- 恢复期把平衡 MPC 的速度参考贴在当拍测量值，估计及预测初始速度照常输入。Kinf 和 LQR 直接屏蔽速度误差分项。恢复时作废旧掩码的在途解，允许尚有效的冻结序列等到新解接管。

用同一估计帧时标对照 1 ms 数据。最少记录模式、接触位和 Fn、两腿长及腿速、气弹簧补偿比例和 Fs、roll 和原始角速度、腿长求解采样 tick 和滤后角速度、名义/候选/分配/接纳四组总力、速率锚与窗口、关节限幅和 CAN 接纳/有效位。判读交接时补记左右轮矩和髋力矩、目标与内部参考高度、pos 权重、停车捕获和当前平衡序列是否有效。对齐后比较同一状态及请求的执行命令。VOFA 模板适合观察趋势，首拍顺序由 1 ms 记录确认。

## 高度合力与速度冻结回放

用当前 30 ms、100% 补偿起点及 0.18 m 目标回放。对照只切换高度合力斜坡，两组都冻结恢复期内的速度参考跟踪。

| 工况 | 直接下发高度合力 | 使用高度合力斜坡 |
|---|---:|---:|
| 双腿同向压缩时，首个 MPC 解的接纳合力增量 | 62.55 N | 6.53 N |
| 双腿同向压缩时，恢复期最大单关节单拍变化 | 3.925 N·m | 0.455 N·m |
| 单侧先触地及单腿回弹时，左右镜像首次接纳纠偏差力 | 确认触地后第 3 拍 | 确认触地后第 3 拍 |
| 单侧镜像用例首解的最大单关节单拍变化 | 12.532 N·m | 12.532 N·m |

联测把恢复期内的机身速度从 0 改到 0.4 m/s，Kinf 四路输出保持相同，恢复窗口结束后重新响应速度误差。切回速度跟踪时可保留有效的冻结序列，等新解发布后接管。回放规定了姿态、速度和接触力，实机是否减轻硬接管仍需同步采样。

## 独立 LAND 改为 MOVING 的历史回放

本表生成时使用 50 ms、0% 补偿起点及 0.20 m 目标。以确认触地为第 0 拍。镜像输入交换先触地的一侧、腿长和腿速，并反转 roll 和角速度。左右有符号总力差取左减右。现用模型的左腿输入增大 roll 角加速度，因此正 roll 且角速度同向时，纠偏请求应为负差力。以下为左侧先触地，右侧先触地时所列差力反号。

| 工况 | 原独立 LAND，带快环速率窗 | 直接 MOVING，普通分配 |
|---|---|---|
| 触地第 0 拍 | LAND，左右接纳总力 155.01/32.01 N | MOVING，左右接纳总力 183.65/58.86 N。触地目标写入 0.20 m |
| 首个腿长解，第 3 拍开始消费 | 名义/候选/分配/接纳差力 −77.00/−75.30/+103.01/+103.00 N | 四级差力 −74.64/−72.95/−72.95/−72.86 N |
| 首次接纳纠偏方向 | 第 9 拍 | 第 3 拍。首解更新时最大单关节命令单拍变化由 1.26 增至 16.89 N·m |
| 单腿先回弹，第 13 拍 | 接纳差力 −77.60 N | 接纳差力 −125.09 N。两侧 Fs 差 1.80 N，当拍给候选差力增加 1.33 N |
| 补偿比例达到 100% | 第 50 拍进入 MOVING | 第 50 拍继续 MOVING。冻结同一组请求并只切换恢复标记时，普通请求和人工关节饱和请求的六路 CAN 命令都保持一致 |
| 低支撑恢复并驻车 | 第 168 拍进入 STANDING | 第 168 拍进入 STANDING，捕获拍 pos 权重为零，随后按原斜坡恢复 |

直行回放的内参考高度首解为 0.2499 m，转弯高度优先条件未触发。后续较低的合力请求与单腿 20 N 下界会限制可分配的差力。镜像夹具规定了姿态轨迹，需要实机同步记录判断落地回正速度、触地瞬间角速度噪声和 CAN 接纳到轴端响应的关系。

## 采样与对照

1. 确认机械行程、可接受的最小腿长和姿态中止线，按本机装配、负载和可用护具确定。把手动失能交给专人。先在支架上核对左右腿长、速度符号、关节方向、接触支持力、气弹簧力和命令反解。记录静止及轻载接触下的噪声幅度和左右差异。
2. 使用同一编译配置、台架、地面、载荷、目标腿高、速度指令和释放方式生成 A/B 样本。A 使用有来源记录的上一版，B 使用本次实现。两份固件均保留相同的采样字段，记录源码快照、编译配置和固件标识。
3. 从最低可重复的受限落差和近零横向速度开始，保留足够机械余量。交替采样 A/B，每档重复数次。先做双轮近同步接触，再做少量单侧先触地的样本。接近已定中止线、出现持续限幅、异常姿态、持续丢帧或重复起跳时停止当前档位。
4. 实际触地时刻用同步的独立接触信号或高速视频标记，记录同步误差。测量实际触地到 `AIR` 下降、首帧 MOVING、首个腿长解被消费的延迟。VOFA 6 ms 帧的拍间变化用估计帧时间或外部同步高速测量补足。
5. 每条腿统计最小腿长、最大压缩速度、回弹幅度或二次离地次数。并列记录俯仰和横滚峰值、关节超界与保护未达到比例、接纳有效率、气弹簧恢复和驻车捕获时刻。压缩期间比较 `S0-Fs` 与 `S_exec-Fs`，仅在对应接纳码可信且帧有效时纳入轴向执行对照。命令反解是估计的已接纳总力，轴端实际响应可与电机力反馈及视频同步交叉核对。
6. 先核对两腿采用同一补偿比例，再确认候选总力的变化是否通过分配和接纳。若首拍滞后，先区分接触确认、速率窗、后台延迟及 CAN 丢帧。若回弹明显，分别比较补偿起始百分比、恢复时间和落地目标值对回弹和限幅的影响。

## VOFA 落地帧

在隔离试验固件的 `Code/Task/vofa_task.c` 中启用 LAND 快照和发送列表最前面的 30 个值，关闭原 48 个生效通道，保持末尾 `INFINITY`。把 `period` 从 10 ms 改为 6 ms。单帧 124 字节，在 230400 baud、8N1 下名义占用约 90%。退出试验时恢复原快照选择、通道和 10 ms 周期。

| 通道 | 内容 |
|---|---|
| 00–04 | 采样 tick、实际控制模式、落地经过 ms（补偿恢复结束后为 −1）、气弹簧补偿百分比、AIR 及左/右接触位 |
| 05–12 | 左/右判定接触支持力 N、腿长 m、伸缩速度 m/s、被动弹簧力 N，各信号按左/右排列 |
| 13–18 | 左/右名义总力、补偿后的候选总力、已接纳总力，各为 N |
| 19 | 位 0–7 关节请求下/上界超出，8–9 补偿请求未达到，10–11 PROJECT 支撑范围放松，12–17 本拍接纳掩码，18–23 执行有效掩码 |
| 20–23 | pitch、roll（rad）、pos 权重、累计停车点捕获次数 |
| 24–29 | 左右分配总力 N、原始 roll 角速度、MPC 滤后 roll 角速度 rad/s、该解使用的估计帧 tick、分配策略（PROJECT 为 0、CLIP 为 1） |

`LEG_CTRL_MODE_AIR = 2`，`MOVING = 7`，`STANDING = 0`。上一版记录中的 8 为历史 LAND 模式。AIR 与非接地状态的分配器数值可能保持前一接地拍，应按模式和有效位剔除。实时估计字段与已发布分配帧可能相差一个控制拍。

主机流程可用 `python -B tests/run_distributor.py --landing` 和 `python -B tests/run_fsm.py --cc <gcc.exe>` 复验。运行 `build/distributor_check/landing.exe left`、`right` 或 `height`，可分别输出左侧先触地、右侧先触地和双腿同向压缩的逐拍 CSV。实机效果以同步采样为准。
