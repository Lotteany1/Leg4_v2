# 自救卡死采集通道

当前启用 `Code/Task/vofa_task.c` 中的 52 路自救诊断帧，原腿长 MPC 帧已整段注释。协议与串口设置不变，JustFloat，`osDelay(10)`，约 100 Hz；DMA 忙时可能丢遥测帧，以 CH0 时间戳为准。

CH 编号从 0 开始，下表“数据列”从 1 开始，不含 VOFA 导出文件自己附加的时间列。保留全部通道及表头，导出 CSV 后提供原始文件，不只提供曲线截图。建议从使能前开始录制，覆盖卡死、换向、成功或最终失败，结束后再多录 2 秒。一次记录单独保留，不拼接。

## 阶段与判读

外层 FSM：0 失能，1 等待使能，2 等待估计帧，3 自救，4 平衡，5 测试。

自救阶段 CH2：0 初始，1 准备，2 公共翻身，3 障碍换向收腿，4 正转收腿，5 正转扫腿，6 反转摆腿，7 反转收腿，8 反转立腿，9 稳定确认，10 平衡交接，11 最终失败。

- 正转卡死：先看 CH22/23 与 CH20/21 的角度误差，再看 CH26/27 的机构速度及 CH7/8 卡死累计时间。
- 反转卡死：先看 CH30/31 的目标速度、CH26/27 的机构速度、CH28/29 的世界速度及 CH36/37 的速度 PID 输出。两种角速度不要混用。
- 换向收腿：CH2=3 时查看 CH14/15 是否真实收短，CH16/17 是否下行，CH40/41 请求和 CH44/45 反馈是否一致。
- 限幅：CH48/49 是累计值，增长表示髋力矩与轴向力合成后触及关节力矩限幅。CH40..43 为限幅前请求，不是限幅后的电机实际出力。
- PID 输出仅在对应控制通道有效；未启用的 PID 可能保留旧值，不要据此判断仍在出力。以 CH40..43 的合成请求和 CH44..47 的反馈共同判读。
- CH7/8 仅记录卡死持续时间。换向看 CH3 变号和 CH6 归零，首次尝试后最多换向重试 5 次，第 5 次重试超时后 CH2 保持 11。
- 通道在单个发送函数的参数列表中直接取样，不保证同一控制帧；目标与合成请求可能处于阶段切换的相邻拍。内部计数通过只读接口取得，关节限幅次数为累计诊断。
