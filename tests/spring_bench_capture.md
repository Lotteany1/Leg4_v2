# 气弹簧单腿台架采集

四个关节都使能，左腿保持零力矩、零位置增益和零速度增益，轮电机保持停止。这次只测右腿慢速压缩时的等效弹簧力。采集后，以**右腿实测腿长（m）**为横轴、**沿腿方向的估算推力（N）**为纵轴拟合一条曲线。后续左右共用这条压缩曲线，意味着假设两侧装配和弹簧特性接近。若要量出弹簧本体的推力曲线，还需测量弹簧销距和弹簧轴上的力。

## 采集条件

日常 EIDE 工程也能直接构建台架镜像。`Code/Config/system_key.h` 中的 `SPRING_CAL_BENCH_ENABLE` 默认是 `1u`，选择右腿专用模式。改成 `0u` 并重新构建即可生成日常固件。它上一行的 `SPRING_CAL_FORCE_RATE` 当前为 `5.0f`，单位为 N/s。使用项目的脚本构建专用镜像时，HEX 文件位于 `Wheel_Leg_Code/build/spring_bench_right/spring_bench_right.hex`。

1. 先在驱动断电时把机身固定在稳定的支撑上。用椅子承托时，固定机身和椅子，确认承受压缩和回弹时都不会滑动或倾翻。让两轮悬空，将自然满伸的右腿朝**铅垂向下**摆正。确认轮子和连杆在收缩、伸回的全程都碰不到地面或椅子，线束也有足够余量。截图中近水平的腿需要先在断电状态摆正，再给驱动上电。
   入场时，右腿静止，腿长为 **356.2–369.2 mm**（CH5），世界系摆角为 **±π/2 rad**（CH7，约为铅垂向下左右各 90°），机身横滚在 **±0.25 rad** 以内（CH21）。扫描期间采用相同的绝对摆角范围。上述条件满足后再由操作者拨杆。记录装配状态，若有温度读数也一并记下。
2. 在 VOFA 连接板上的 LPUART1，串口设为 **209700 baud、8N1**，协议选 **JustFloat**。确认有 28 路数据且 CH10 为 5，再启动 CSV 记录。先把左右拨杆都置于下档复位，再保持右杆下档、把左杆拨到中档，进入 TEST 并开始一趟扫描。记录开始时应能看到待机样本。
3. 观察 CH0 反馈轴力、CH9 请求轴力、CH3 阶段和 CH5 腿长。扫描从 1 N 起步，到 221.7 N 前最多加力 1 N/s，之后最多加力 0.1 N/s，收腿过快时保持当前请求力。腿长进入 174 mm 短端区时保持当时的请求力，直到手动退出 TEST。正常采集没有总时限或推进时限。请求力上限见 system_key.h 的 SPRING_CAL_FORCE_MAX_N，实测轴力绝对值达到该值 仍会保护停机。中止（3）的记录也请保存，附上 CH4 原因码。
4. 重新采集前将两杆都拨回下档复位，再进 TEST。保持相同工况，建议录三趟完整压缩，留一整趟检验预测误差。每趟保存原始 CSV，保留起点、末点和退出后的记录，可用 `right_pass_01.csv` 一类文件名区分。拟合所用长度范围限于有效样本覆盖区间。

动作期间让台架自行承受载荷。手扶轮子、腿杆抵住限位或轮子碰地都会改变力的读数。若有接触，立即将拨杆拨出 TEST 并在记录中标明。收到新的退档输入后，控制器会在第一控制拍发送失能指令。遥控完全没有有效新帧时，超过 100 ms 才判定失联。电机撤力还取决于失能指令能否送达，现场应保留可直接切断驱动供电的手段。退出 TEST 撤力后，气弹簧可自行把腿弹回，整个回程也要保持悬空并留足空间。

## CSV 通道

这份专用固件按下列顺序发送一帧，名义频率 100 Hz。VOFA 导出的 `I0… I27` 对应 `CH0… CH27`。协议 1 同样有 22 路，使用旧起点和摆角设置，CH18 只含腿的自重项。保存原始协议号和精度，尤其是实测腿长、腿速以及力矩的小数位。

| 通道 | 含义 | 单位或取值 |
| --- | --- | --- |
| CH0 | 右腿电机反馈力矩换算的轴力，伸腿为正、收腿为负 | N |
| CH1 | 本趟已过时间 | ms |
| CH2 | 趟号 | 计数 |
| CH3 | 阶段 | 0 待机，1 扫描，2 完成，3 中止 |
| CH4 | 停止原因码 | 整数 |
| CH5 | 实测右腿长 | m |
| CH6 | 右腿伸缩速度，压缩为负 | m/s |
| CH7 | 世界坐标系中的右腿角 | rad |
| CH8 | 限速修正后的收腿力幅值，等于 −CH9 | N |
| CH9 | 右腿电机请求轴力，以伸腿方向计正 | N |
| CH10 | 台架协议版本 | 5 |
| CH11 | 悬空时抵住腿和轮自重所需的轴力 | N |
| CH12 | 等效弹簧推力估计，CH11 减 CH0，以伸腿方向计正 | N |
| CH13 | 当拍是否满足拟合样本条件 | 0 否，1 是 |
| CH14 | 右前关节反馈力矩 | N·m |
| CH15 | 右后关节反馈力矩 | N·m |
| CH16 | 前、后关节成对反馈样本序号 | 计数 |
| CH17 | 两个关节反馈力矩换算的电机合成髋矩 | N·m |
| CH18 | 悬空时抵住腿和轮自重所需的髋矩，协议 2 已计入轮的重力项 | N·m |
| CH19 | 当拍髋矩请求，含摆角反馈 | N·m |
| CH20 | 右腿在世界坐标系中的角速度 | rad/s |
| CH21 | 机身横滚角 | rad |
| CH22 | 本趟最近一次检查的关节使能回报，停止后保留 | 右前=1、右后=2、左前=4、左后=8，相加为 15 表示四台均回报使能 |

CH4 的取值如下。原因码应结合 CH3 所在阶段查看。

| 码 | 含义 | 码 | 含义 |
| --- | --- | --- | --- |
| 0 | 无 | 6 | 伸缩超速 |
| 1 | 正常结束 | 7 | 堵转 |
| 2 | 起始位置不符合要求 | 8 | 扫描超时 |
| 3 | 反馈、握手或控制缺拍 | 9 | 腿长越界 |
| 4 | 关节超界或发送失败 | 10 | 退出 TEST |
| 5 | 轴力超限 | 11 | 角度越限 |

发送 CSV 时附上是否完成、是否发生过接触，每趟来自哪次进入 TEST。后续按 CH2 区分趟次，以 CH3、CH6、CH13、CH16 和整趟走势核对慢速压缩样本。原始记录保留从自然满伸开始的全程。现有重力标定表仅到 340 mm，长于 340 mm 时 CH13 为 0，这段原始腿长、速度和力矩可用来检查起步。拟合时只使用 CH13=1 的样本，并保留短端 8 mm 的排除范围。CH8、CH9 用来解释台架施加了多大收缩指令，拟合目标取 CH12。

## 怎样理解力的读数

台架用 `F_ref = F_gravity_hold - F_motor_feedback` 估算伸腿方向的等效弹簧推力。`F_gravity_hold` 是在当前姿态下抵住腿和轮自重所需的电机轴力，`F_motor_feedback` 是关节反馈力矩换算的电机轴力，单位均为 N。机身固定、轮子悬空、动作足够慢时，两者的差才能近似反映弹簧的作用。关节摩擦、力矩换算或自重估计的误差也会出现在这个差值里。

若手头有同一侧卸下弹簧后按相同姿态、行程、方向与速度取得的基线，可随装簧数据一起提供。比较相同腿长下的两条曲线，有助于估计重复出现的自重及摩擦偏差。若有独立力传感器记录，请附上它的测力方向、单位及与 CSV 对齐的时刻。

若还想看是否有摆腿方向的影响，可在速度较慢、摆角相近时对照 CH17 和 CH18，并用 CH7、CH19、CH20 核对实际摆角、控制请求和角速度。两者的力矩差也会包含摩擦、自重模型误差等。机身固定时的 CH21 记录台架是否倾斜，测量轮子侧向受力则需要相应方向的独立测力。

入档诊断见 CH23：0 遥控离线，1 IMU 离线，2 等待左拨杆下档准备，3 已准备，4 四关节握手，5 正在采集，6 本趟已结束，7 估计帧超时。左下准备后切到左中右下进入 TEST。CH24～27 顺序为右前、右后、左前、左后。每台 0 等清错发送、1 等清错应答、2 等使能发送、3 等使能应答、4 已确认。中止后保留握手阶段，结合 CH4 判断停车原因。
